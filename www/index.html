C++98 HTTP Server

Webserv

A lightweight HTTP/1.1 server built from scratch with poll(), non-blocking I/O, and CGI support.

Endpoints

📁
Directory Listing autoindex on /files/
📤
Upload Files POST multipart + autoindex
⚙
CGI Python /cgi-bin/hello.py
⚙
CGI Bash /cgi-sh/hello.sh
⚙
CGI Perl /cgi-pl/hello.pl
📄
CGI Environment All env variables
↺
Redirect Test 301 /old-page -> /
❌
404 Error Test Custom error page

Architecture

poll() loop ── accept ── recv ── parse ── route ── respond ── send
    |                                        |
    +──── CGI pipes (fork + execve) ─────────+
